# Задание 1
## Задача 3
### Текст задачи
Имена. Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:
- Клеопатра
- Пушкин Александр Сергеевич
- Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.
### Алгоритм решения
1. Создан класс `Name` с тремя закрытыми полями: `lastName` (фамилия), `firstName` (личное имя), `middleName` (отчество).
2. Конструктор принимает все три значения. Если часть имени не задана, вместо неё передаётся `null`.
3. В методе `toString()` берётся пустая строка, и к ней по очереди добавляются фамилия, имя и отчество, но только те, которые не равны `null`. После каждой части ставится пробел.
4. В конце вызывается `trim()`, чтобы убрать лишний пробел справа.
5. В `main` создаются три имени: `new Name(null, "Клеопатра", null)`, `new Name("Пушкин", "Александр", "Сергеевич")`, `new Name("Маяковский", "Владимир", null)` и выводятся на экран.

Результат:
```
Клеопатра
Пушкин Александр Сергеевич
Маяковский Владимир
```

## Задача 4
### Текст задачи
Время. Создайте сущность Время, которое будет описывать текущее время суток в 24-х часовом формате. Время описывается числом секунд, прошедшим с начала суток. Время может быть приведено к текстовой форме следующего формата: "ЧЧ:ММ:СС". Например, если время задано как 12000, то текстовая форма будет "3:20:00". Если общее время превышает 24 часа, то отображаться в текстовом виде должно только то время, которое прошло с начала последних суток, например 91800, это не 25:30:00, а 1:30:00.

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:
- 10 секунд
- 10000 секунд
- 100000 секунд
### Алгоритм решения
1. Создан класс `Time` с одним полем `totalSeconds`: количество секунд с начала суток.
2. Чтобы получить часы, сначала отбрасываются полные сутки (`totalSeconds % 86400`), затем результат делится нацело на 3600.
3. Минуты: остаток от деления на 3600 (секунды внутри текущего часа), делённый нацело на 60.
4. Секунды: остаток от деления на 60.
5. `toString()` склеивает строку `часы:минуты:секунды`. Минуты и секунды всегда выводятся двумя цифрами: если число меньше 10, впереди дописывается `0`.
6. В `main` создаются объекты `new Time(10)`, `new Time(10000)`, `new Time(100000)` и выводятся на экран.

Результат:
```
10 секунд     -> 0:00:10
10000 секунд  -> 2:46:40
100000 секунд -> 3:46:40
```

# Задание 2
## Задача 4
### Текст задачи
Сотрудники и отделы. Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: "Имя работает в отделе Название, начальник которого Имя". В случае если сотрудник является руководителем отдела, то текстовая форма должна быть "Имя начальник отдела Название".

Необходимо выполнить следующие задачи:
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).
### Алгоритм решения
1. Создан класс `Department` (отдел) с полями `name` (название) и `boss` (начальник, тип `Employee`). Начальник назначается методом `setBoss()`.
2. Создан класс `Employee` (сотрудник) с полями `name` (имя) и `department` (отдел, тип `Department`).
3. В `main` создаётся один объект отдела `IT`, и ссылка на него передаётся в конструктор всех трёх сотрудников. Поэтому у всех троих один и тот же отдел (один объект в памяти).
4. Методом `it.setBoss(kozlov)` Козлов назначается начальником. Так как отдел общий, начальник сразу становится общим для всех троих.
5. В `toString()` сотрудника проверяется, является ли он начальником своего отдела: сравниваются ссылки `department.getBoss() == this`.
   - если да, возвращается строка "Имя начальник отдела Название";
   - если начальник ещё не назначен, выводится "начальник пока не назначен";
   - иначе возвращается "Имя работает в отделе Название, начальник которого Имя".

Результат:
```
Петров работает в отделе IT, начальник которого Козлов
Козлов начальник отдела IT
Сидоров работает в отделе IT, начальник которого Козлов
```

# Задание 4
## Задача 4
### Текст задачи
Создаем Время. Измените сущность Время из задачи 1.4. Новые требования включают:
- Время можно создать указав количество секунд с начала суток
- Время можно создать указав количество часов, минут, секунд текущего времени.
- Гарантируйте, что операция присвоения в инициализаторах будет использована не более одного раза

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:
1. 10000 секунд
2. 2 часа, 3 минуты, 5 секунд
### Алгоритм решения
1. В классе `Time` два конструктора (перегрузка конструкторов):
   - `Time(int totalSeconds)`: единственное место, где полю присваивается значение;
   - `Time(int hours, int minutes, int seconds)`: ничего не присваивает сам, а переводит часы и минуты в секунды и вызывает первый конструктор через `this(hours * 3600 + minutes * 60 + seconds)`.
2. Поле `totalSeconds` объявлено как `final`. Компилятор не даст присвоить его второй раз, значит присвоение действительно происходит ровно один раз.
3. В `main` создаются `new Time(10000)` и `new Time(2, 3, 5)` и выводятся на экран.

Результат:
```
10000 секунд               -> 2:46:40
2 часа, 3 минуты, 5 секунд -> 2:03:05
```

# Задание 5
## Задача 4
### Текст задачи
Сколько сейчас времени? Измените сущность Время из задачи 4.4. Добавьте ей возможность возвращать следующие сведения:
- Какой сейчас час (целое число)
- Сколько минут прошло с начала текущего часа (целое число)
- Сколько секунд прошло с начала текущей минуты (целое число)

Необходимо выполнить следующие задачи:
1. Вывести на экран сколько часов соответствуют времени 34056
2. Вывести на экран сколько минут соответствуют времени 4532
3. Вывести на экран сколько секунд соответствуют времени 123
### Алгоритм решения
1. В класс `Time` добавлены три метода:
   - `getHours()`: `totalSeconds % 86400 / 3600`;
   - `getMinutes()`: `totalSeconds % 3600 / 60`;
   - `getSeconds()`: `totalSeconds % 60`.
2. Метод `toString()` теперь тоже использует эти три метода, чтобы формула была записана только в одном месте.
3. Проверка вручную:
   - 34056 / 3600 = 9 (остаток 1656), значит час 9;
   - 4532 % 3600 = 932, 932 / 60 = 15, значит 15 минут;
   - 123 % 60 = 3, значит 3 секунды.

Результат:
```
Время 34056 (9:27:36): часов = 9
Время 4532 (1:15:32): минут = 15
Время 123 (0:02:03): секунд = 3
```
